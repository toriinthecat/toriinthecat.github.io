⚠ Expect a warning: this software is not code-signed yet

When you download it (your browser says "may be dangerous" or "isn't commonly downloaded") and when you start it (Windows says "Windows protected your PC"), a warning screen appears. It shows up because there is no signature; it is not the result of anyone examining this software.

If you are unsure, check these two things before going on:

  1. The file came from this site (dl.toriinthecat.com).
  2. The file's SHA-256 matches the value in the table below (how to check is under "First start").

If both match and you choose to go on, pick "Keep" in the browser and "More info" then "Run anyway" in Windows. If you cannot check, please do not go on, and do not use it.

As more people download and use it, the warning may appear less often (Windows SmartScreen also looks at how widely a file has been downloaded). A new version can bring it back.

Install from the command line

You can also install without a browser. The scripts connect to dl.toriinthecat.com only when you run them, and check the signature and SHA-256 before installing.

Windows (PowerShell)

iwr https://dl.toriinthecat.com/install/install.ps1 -OutFile install.ps1
.\install.ps1            # latest version (current user, no administrator)
.\install.ps1 -List      # list versions

Linux (apt: Debian, Ubuntu, Linux Mint)

curl -fsSL https://dl.toriinthecat.com/apt/vault-zip.gpg | sudo tee /usr/share/keyrings/vault-zip.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/vault-zip.gpg] https://dl.toriinthecat.com/apt stable main" | sudo tee /etc/apt/sources.list.d/vault-zip.list
sudo apt update && sudo apt install vault-zip

Linux (script)

curl -fsSLO https://dl.toriinthecat.com/install/install.sh
sh install.sh --user      # no sudo: AppImage and CLI under ~/.local

The right-click menu on Linux

Items such as "Vault-ZIPで圧縮" (compress) appear in the file manager's right-click menu. Nemo (Linux Mint Cinnamon), Dolphin (KDE), Nautilus (GNOME) and Thunar (Xfce) are supported. Caja (MATE) is not supported yet.

  • With the deb, the package installs the Nemo and Dolphin items. The Thunar and Nautilus items are written to your own settings folder when Vault-ZIP starts. They stay after the package is removed; delete them from the settings file if you no longer want them.
  • On Xfce, the items do not appear when you right-click icons on the desktop (over the wallpaper). The Xfce desktop has no way to add items. Right-click files inside a Thunar window instead.

System requirements

Also neededMicrosoft Edge WebView2 Runtime. Part of Windows 11 and present on most Windows 10 PCs. Where it is missing, the installer downloads it from Microsoft (the installer connects only in that case).
DiskAbout 55 MB once installed (the installer itself is about 15 MB). The ledger and settings grow only as you use them.

First start

Vault-ZIP is not code-signed yet, so Windows and your browser will warn you when you download or start it.

  1. If "Windows protected your PC" appears, click "More info", then "Run anyway" (screens below; the Windows here is in Japanese).
  2. Check that the file's SHA-256 matches the value above before running it.

On a PC with Windows 11 Smart App Control turned on, unsigned apps may not start.

Uninstalling

Uninstall Vault-ZIP from Settings → Apps → Installed apps. Uninstalling keeps your password ledger and settings (there is no screen asking whether to delete them), so a reinstall carries on where you left off. To remove the ledger too, delete its folder (%APPDATA%\VaultZip) yourself after uninstalling. This cannot be undone.
