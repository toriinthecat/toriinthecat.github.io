How Vault-ZIP works

  • No connection you did not ask forNo automatic update check, no usage reporting, no account, no licence server. The background traffic of the window component (WebView2) is switched off too: in our measurement, nothing left the PC in the first 100 seconds after start.
  • Nothing overwritten, nothing deletedA name already taken gets " (2)". Originals go to the Recycle Bin only when you choose it for that job, and only after the new ZIP has been checked.
  • The same folder on every systemOld Japanese Shift_JIS names, macOS names and extra files, and names Windows cannot hold are made consistent when extracting.
  • Checked before it is doneThe new ZIP is read back to make sure every file comes out as it went in.

Features

  • Encrypted ZIP filesAES-256 (WinZip AES). They open in any tool that supports it, such as 7-Zip and Windows 11 File Explorer.
  • A password ledgerEach ZIP's password is kept with its date, file name and a note, encrypted, on your PC.
  • Checked after writingThe finished ZIP is read back in full before it counts as done (can be turned off).
  • Many formats to extractZIP, 7z, RAR, tar, gz, bz2, xz, zst, CAB and MSI, recognised by content.
  • PDF passwordsAdds an AES-256 password to a PDF and records it in the ledger.
  • What is this file?Tells a file's type from its content, not its extension, and which apps usually open it. The file is not opened.
  • See what is insideLists the contents of a ZIP, 7z or RAR without extracting.
  • Right-click menuCompress, extract and identify from File Explorer, including the Windows 11 menu.
  • Recovery key and backupsWrite the ledger, encrypted, to another place for a new PC or a lost key.
  • Command lineA command-line tool for RPA such as Power Automate for desktop. Passwords go through standard input.
  • Portable versionRuns from a folder without installing.
  • Safe extractionStops entries that would write outside the folder, symbolic links and archives that grow huge when extracted. Names Windows cannot use and invisible characters that disguise an extension are replaced and reported.
  • Passwords kept off screen capturesAn option keeps a window showing a password out of screen sharing and screenshots. Copied passwords stay out of the clipboard history and are cleared after a while.
  • Management for organisationsRules such as "no ZIP without a password" can be deployed through Group Policy or Intune (licence required).

Please note

  • If the ledger's key, the recovery key and every backup are lost, nobody can open the ledger, including us. Make a recovery key or a backup.
  • If you forget a ZIP's password and it is not in the ledger, nobody can get the contents back, including us.
  • Vault-ZIP never sends your files, passwords or ledger anywhere without your action (privacy).
