コマンドライン版

自動化（RPA など）で使うための vault-zip-cli の案内です。GUI と同じ台帳を使い、両方を同時に動かせます。

はじめに

  • パスワードは引数に書きません。標準入力から渡します（--pass-stdin）。--password のような指定はありません。
  • 結果を機械で読むときは --json を付けます。1 回の実行で JSON が 1 つ出ます。
  • すでにあるファイルは上書きしません。

主なコマンド

vault-zip-cli compress -i 資料フォルダ --json              # 作る（パスワードは自動で作り、台帳に記録）
vault-zip-cli compress -i 資料フォルダ --each             # 中の項目ごとに 1 つずつ作る
vault-zip-cli extract  -i 資料.zip -o 取り出し先 --json   # 台帳のパスワードで取り出す
vault-zip-cli pdf encrypt -i 報告書.pdf --json            # PDF にパスワードをかける
vault-zip-cli pdf decrypt -i 報告書_暗号化.pdf            # パスワードを外した複製を作る
vault-zip-cli pdf check   -i 報告書.pdf --json            # PDF の状態を調べる（変更しません）
vault-zip-cli identify ファイル... --json                 # 何のファイルか、中身から調べる
vault-zip-cli search 検索語 --json                        # 台帳から探す
vault-zip-cli reveal <ID>                                 # 台帳のパスワードを表示する
vault-zip-cli status --json                               # 台帳とバックアップの状態

ほかに、バックアップ（backup）、回復キー（recovery-key）、設定（settings）、ライセンス（license）、管理者のポリシー（policy）のコマンドがあります。vault-zip-cli --help で一覧を見られます。

パスワードを自分で決めるとき

echo 自分で決めたパスワード| vault-zip-cli compress -i memo.txt --pass-stdin --json

パスワードは 1〜128 文字の英数字と記号（ASCII）です。作ったパスワードを画面に出す --print-password は、実行の記録に残るので、自動処理では使わないでください。

元のファイルをごみ箱へ（--purge）

圧縮して中身を確かめたあとに、元のファイルをごみ箱へ移します（デスクトップ版のみ）。元のファイルが ZIP と同じ内容のままで、ごみ箱に入れられるときだけ動き、完全には削除しません。条件に合わないときは元のファイルを残し、終了コード 4 を返します。

終了コード

終了コード意味
0成功
2引数の誤り
3一部だけ失敗（--each など）。ほかは成功
4--purge：ZIP は作れたが、元のファイルは残した
10入力が見つからない
11出力先がすでにある（上書きしていません）
12空き容量が足りない
13そのほかの読み書きの失敗
20使えるパスワードがない
21パスワードが違う
22データが壊れている、または書き換えられている
23安全のための確認で拒否した
24アーカイブではない、または未対応の機能
25アーカイブが壊れている
26見分けはついたが、Vault-ZIP では読めない形式
29項目が 10 万を超えた（--allow-many-entries が必要）
30台帳のデータベースのエラー
31台帳はあるが、鍵が見つからない
32OS のキーストアのエラー
33ポータブル版：パスフレーズが違う
40バックアップのエラー
41ライセンスファイルが正しくない
42管理者のポリシーで許可されていない
50中止された
60PDF を拒否した（すでに暗号化済み、署名つきなど）
70予期しない内部エラー

結果の JSON には、ok、エラーの code、警告の warnings などが入ります。ポータブル版は --unlock-stdin でパスフレーズを渡します。自動処理には、インストール版をおすすめします。
