「一般的な圧縮・展開ソフト」の欄は、よく使われるソフトに多い傾向を書いたもので、ソフトや版によって違います。お使いのソフトの説明をご確認ください。「Windows 標準の ZIP 機能」は Windows 11 のエクスプローラーで、「（未確認）」はまだ試していない項目です。

Vault-ZIP が苦手なこと

  • RAR や 7z の形式で作ること（Vault-ZIP が作るのは ZIP だけです。展開はできます）。
  • ZIP の中のファイル名まで隠すこと（ZIP の決まりでできません。安心して使ってもらうための工夫の最後を見てください）。
  • Mac と iPhone で使うこと（今は Windows だけです。Android は準備中です）。

仕組みのくわしいお話は安心して使ってもらうための工夫に、確かめた互換性と速さは機能と仕様にあります。
