コマンドでインストールする

ブラウザーを使わず、コマンドで入れることもできます。スクリプトは、打ったときだけ dl.toriinthecat.com につながり、署名と SHA-256 を確かめてから入れます。

Windows（PowerShell）

iwr https://dl.toriinthecat.com/install/install.ps1 -OutFile install.ps1
.\install.ps1            # 最新の版（自分だけ。管理者は不要）
.\install.ps1 -List      # 版の一覧

Linux（apt：Debian、Ubuntu、Linux Mint）

curl -fsSL https://dl.toriinthecat.com/apt/vault-zip.gpg | sudo tee /usr/share/keyrings/vault-zip.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/vault-zip.gpg] https://dl.toriinthecat.com/apt stable main" | sudo tee /etc/apt/sources.list.d/vault-zip.list
sudo apt update && sudo apt install vault-zip

Linux（スクリプト）

curl -fsSLO https://dl.toriinthecat.com/install/install.sh
sh install.sh --user      # sudo なし。AppImage と CLI を ~/.local に

Linux の右クリックメニュー

ファイルマネージャーの右クリックに、「Vault-ZIPで圧縮」などの項目が出ます。対応しているのは、Nemo（Linux Mint の Cinnamon）、Dolphin（KDE）、Nautilus（GNOME）、Thunar（Xfce）です。Caja（MATE）には、まだ対応していません。

  • deb で入れると、Nemo と Dolphin の項目はパッケージが入れます。Thunar と Nautilus の項目は、Vault-ZIP を起動したときに、お使いの設定フォルダーへ書き込まれます。パッケージを削除しても残るので、不要になったら設定ファイルから消してください。
  • Xfce では、デスクトップ（壁紙の上のアイコン）の右クリックには出ません。Xfce のデスクトップの仕様で、項目を足せないためです。Thunar のウィンドウの中でファイルを右クリックしてください。

動作環境

OSWindows 10 以上（64 ビット、x64）。ARM 版 Windows では確かめていません。Linux は x64 の Debian 系（Linux Mint 22 など）。
必要なものMicrosoft Edge WebView2 ランタイム。Windows 11 には入っています。Windows 10 でも、多くの場合は入っています。無い PC では、インストーラーが Microsoft から取得します（このときだけ通信が生じます）。
ディスクインストール後は約 55 MB です（インストーラー自体は約 15 MB）。台帳と設定は、使った分だけ増えます。

はじめて起動するとき

Vault-ZIP には、まだコード署名をしていません。そのため、ダウンロードや起動のときに、Windows やブラウザーの警告が出ることがあります。

  1. 「Windows によって PC が保護されました」と出たら、「詳細情報」を押し、「実行」を押します（下の画面）。
  2. ダウンロードしたファイルは、上の SHA-256 と同じかを確かめてから実行してください。

Windows 11 の「スマート アプリ コントロール」がオンの PC では、署名の無いアプリを起動できないことがあります。

アンインストール

「設定」→「アプリ」→「インストールされているアプリ」から Vault-ZIP をアンインストールします。アンインストールしても、パスワードの台帳と設定は残ります（消すかどうかを選ぶ画面はありません）。入れ直せば、そのまま続けて使えます。台帳ごと消したいときは、アンインストールのあとに、台帳のフォルダ（%APPDATA%\VaultZip）を自分で削除してください。削除は元に戻せません。
