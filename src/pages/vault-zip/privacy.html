Vault-ZIP のプライバシー

最終更新日: 公開日

草案です。公開の前に内容をご確認ください。

このページは、Vault-ZIP（Windows 版、Android 版、コマンドライン版）での情報の取り扱いを説明します。Toriinthecat のプライバシーポリシーに定めるとおり、Vault-ZIP についてはこのページの記載が優先されます。

1. 送信しない情報

Vault-ZIP は、利用者のファイル、パスワード、台帳の内容を、利用者の操作なしに外部へ送信しません。当方はサーバーを運営しておらず、アカウントの登録もありません。利用状況の分析、広告、トラッキングのためのツールは組み込んでいません。更新の自動確認もしません。なお、当サイトとダウンロード用サーバーでの閲覧数・ダウンロード数の集計は、Cookie を使わず個人を追跡しない形で行っています（プライバシーポリシーの第 6 項）。これは Vault-ZIP の中には入っていません。

Windows 版の画面は、Microsoft の部品（WebView2）が描きます。WebView2 は、何もしなくても Microsoft のサーバーへ接続することがあるため、Vault-ZIP はその自発的な通信を止める設定で画面を開きます。WebView2 自体の更新は、ほかのアプリと同じく Windows と Microsoft Edge の更新に任せています。

2. PC・デバイスの中に保存する情報

  • 台帳：作った ZIP や PDF の名前、日時、パスワード、メモなど。暗号化して保存します。鍵は Windows の資格情報マネージャー（Android ではデバイスのキーストア）に保存します。ポータブル版では、利用者が決めたパスフレーズで守ります。
  • 設定と作業の記録。

保存場所は、インストール版では %APPDATA%\VaultZip、ポータブル版では展開したフォルダーの中です。

3. 利用者の操作で外部とやりとりするもの

  • ファイルの開き方の案内などのリンクを押したとき、ブラウザーでそのページを開きます。
  • バックアップの保存先に、クラウドと同期するフォルダーを選んだ場合、暗号化したバックアップがそのサービスに送られます。
  • メールや共有の機能を使ったとき、選んだアプリに内容が渡ります。
  • 設定で外部ツール（7-Zip など）を有効にした場合、そのツールにファイルを渡して展開させます。Vault-ZIP からは通信を求めません。

このほか、WebView2 ランタイムが入っていない PC では、インストーラーが Microsoft からランタイムを取得します。

4. ライセンスの確認

組織向けのライセンスは、PC の中だけで確かめます。確認のための通信はしません。
