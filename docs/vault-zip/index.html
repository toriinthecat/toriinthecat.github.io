Vault-ZIP

パスワードを忘れても、Vault-ZIP は覚えている。

AI 時代に対応する、Rust で書かれたセキュアな圧縮・解凍ソフトです。大切なファイルに、そっと鍵をかけておけます。勝手に通信もしません。

ダウンロード

こんなこと、ありませんか？

  • パスワードを付けた ZIP を、あとで開けなくなってしまった。
  • 「パスワードは別のメールで送ります」の、そのパスワードがどこにあるか分からない。
  • 届いた ZIP を開いたら、ファイル名が文字化けしていた。
  • メールで届いたファイル、開いても大丈夫かな、と少し不安になる。

Vault-ZIP は、そんな小さな困りごとをなくしたくて作りました。

Vault-ZIP がしてくれること

  • ちゃんと覚えています作った ZIP のパスワードを、暗号化した台帳に自動で記録します。自分の ZIP は、入力しなくても開けます。
  • ていねいに確かめます作った ZIP を最後まで読み直して、全部のファイルが元どおり取り出せることを確かめてから完成にします。
  • 外には出しません更新の自動確認も、使い方の送信もありません。計測で、外への接続が 0 件だったことを確かめています。

安心して使ってもらうための工夫 → ・ ほかの方法とくらべてみると →

できること

  • パスワード付きの ZIP を作るAES-256（WinZip AES 形式）で暗号化します。7-Zip や Windows 11 のエクスプローラーなど、この形式に対応したソフトで開けます。
  • パスワードの台帳作った日時、ファイル名、メモと一緒に記録します。台帳は暗号化して、この PC の中にだけ保存します。
  • いろいろな形式を開くZIP、7z、RAR、tar、gz、bz2、xz、zst、CAB、MSI を、中身から見分けて展開します。
  • 文字化けしにくい古い Windows で作った日本語の名前や、Mac で作った名前も、きれいにそろえて展開します。
  • PDF にもパスワードPDF に AES-256 のパスワードを付けて、台帳に記録します。
  • 何のファイルか調べる拡張子ではなく中身から、ファイルの種類と、ふつう何のアプリで開くかを教えてくれます。ファイルは開きません。
  • 開く前に中身をのぞくZIP、7z、RAR の中身の一覧を、展開しないで見られます。
  • 右クリックからすぐにエクスプローラーの右クリックで、圧縮、展開、調べるができます。Windows 11 の新しいメニューにも出ます。
  • 怪しいファイルから守るフォルダーの外に書き出そうとするファイルや、開くと巨大になるファイルを止めます。見えない文字で拡張子をごまかした名前も、置き換えてお知らせします。
  • パスワードを人に見せない表示の前に本人確認。画面共有に写さない設定もあります。コピーしたパスワードは、しばらくすると消えます。
  • もしものための備え回復キーと、暗号化したバックアップを作れます。PC を買い替えたときも安心です。
  • 上書きしません同じ名前のファイルがあれば (2) を付けます。知らないうちに上書きすることはありません。
  • 持ち運べる版もインストールしないで、フォルダーごと持ち運んで使えるポータブル版があります。
  • お仕事の自動化にもRPA や AI エージェントから使えるコマンドライン版付き。パスワードは記録に残らない方法で渡します。
  • 会社で使うときはパスワードなしの ZIP を禁止するなどのルールを、管理者がまとめて設定できます（ライセンスが必要です）。

このソフトについて

パスワード付きの ZIP は便利ですが、パスワードを忘れたら、中身は誰にも取り出せません。だから Vault-ZIP は「ちゃんと覚えておく」ことから作り始めました。

大切なファイルを預けてもらうソフトなので、見えないところこそ、ていねいに作り、確かめています。作り方と確かめ方は、note の開発記に書いています。

開発記、書いています（note）

ソフトができるまでの過程を、note に書いています。どう設計したか、どこでつまずいたか、どうやって確かめたか、なぜそう決めたか。うまくいかなかったことも、そのまま書いています。

知っておいてほしいこと

  • 台帳の鍵、回復キー、バックアップをすべてなくしてしまうと、作者にも台帳は開けません。回復キーかバックアップを、ひとつ作っておいてください。
  • ZIP のパスワードを忘れて、台帳にも残っていないときは、作者にも中身を取り出せません。
  • Vault-ZIP は、ファイル、パスワード、台帳の内容を、あなたの操作なしに外へ送ることはありません（プライバシー）。
