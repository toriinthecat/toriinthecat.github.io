よくある質問

無料で使えますか。
個人の方は無料です。仕事で使う場合（個人事業主、副業を含む）も無料です。学校などの教育機関も、申請なしで無料で使えます。企業・官公庁・非営利法人などの組織で使う場合は、1 台につき 1,000 円のライセンスが必要です（ライセンス）。
Vault-ZIP で作った ZIP は、Vault-ZIP が無い PC でも開けますか。
開けます。AES-256 で暗号化した ZIP（WinZip AES 形式）に対応したソフトなら、パスワードを入力して開けます。7-Zip と Windows 11 のエクスプローラーで開けることを確かめています。パスワードを付けずに作った ZIP は、どのソフトでも開けます。
パスワードを忘れました。
Vault-ZIP で作った ZIP なら、台帳にパスワードが記録されています。台帳を開いて、ファイル名や日付で探してください。台帳に無いパスワードは、作者にも調べられません。
PC を替えたら、台帳はどうなりますか。
台帳は PC の中にあり、その PC の鍵で暗号化しています。PC を替える前に、設定からバックアップを書き出し、新しい PC で読み込んでください。回復キーも作っておくと安心です。
ファイルやパスワードがインターネットに送られることはありますか。
ありません。Vault-ZIP は、ファイル・パスワード・台帳の内容を、利用者の操作なしに外部へ送信しません。アカウントの登録もありません。更新の自動確認もしません。画面の部品（Microsoft の WebView2）が自分で行う通信も止めています（プライバシー）。
ダウンロードや起動のときに警告が出ます。
Vault-ZIP にはまだコード署名をしていないため、Windows の警告が出ることがあります。手順はダウンロードのページにあります。ダウンロードしたファイルの SHA-256 が、ページに載っている値と同じかを確かめてから実行してください。
どんな形式を展開できますか。
ZIP、7z、RAR、tar、gz、bz2、xz、zst、CAB、MSI です。形式は拡張子ではなく中身で見分けます。ほかの形式は、外部のツールを設定すると展開できるものもあります（機能と仕様）。
古いソフトで作った ZIP のファイル名が文字化けします。
Vault-ZIP は、Shift_JIS で名前を書いた古い日本語の ZIP を自動で見分け、正しい名前で展開します。Mac で作った ZIP の濁点が分かれる名前もそろえ、__MACOSX フォルダーと ._ で始まるファイルは作りません（設定で変えられます）。
ファイル名が変わって展開されました。
Windows で使えない名前（CON、? や : を含む名前など）や、拡張子を偽るのに使われる見えない文字を含む名前は、使える名前に置き換えて展開します。どの名前を置き換えたかは、展開の結果に一覧で出ます。
Windows 10 で使えますか。
使えます。Windows 10 以上の 64 ビット版（x64）に対応しています。Windows 11 の新しい右クリックメニューは Windows 11 だけで、Windows 10 では従来の右クリックメニューに出ます。ARM 版 Windows では確かめていません。
画面共有中にパスワードを表示しても大丈夫ですか。
設定の「パスワードの表示中は画面共有や撮影に写さない」をオンにすると、パスワードを表示しているウィンドウは、画面共有・録画・スクリーンショットに写りません（Windows 10 バージョン 2004 以降）。既定はオフです。組織では、管理者がこれを常にオンにできます。
RPA から使えますか。
コマンドライン版 vault-zip-cli.exe が付いています。結果を JSON で受け取れ、終了コードで成否を判定できます。パスワードは標準入力で渡します。
不具合を見つけました／要望があります。
support@toriinthecat.com までメールでお知らせください。Windows の版、Vault-ZIP の版、操作の手順を書いていただけると助かります。パスワードやファイルそのものは送らないでください。
