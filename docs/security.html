セキュリティの連絡先

最終更新日: 2026年11月4日

Toriinthecat のソフトウェア（Vault-ZIP ほか）に脆弱性を見つけた場合は、次の窓口へお知らせください。

報告の送り先

support@toriinthecat.com（件名の先頭に「[Security]」と付けてください）

次のことを書いていただけると、早く確かめられます。

  • ソフトウェアの名前と版（Vault-ZIP では「設定 → このアプリについて」に表示されます）
  • OS とその版
  • 再現の手順と、起きたこと
  • 再現に使ったファイル（他人の秘密や個人情報を含まないもの）

実際のパスワード、秘密鍵、他の人のファイルは送らないでください。

報告を受けたあと

  1. 7 日以内に、受け取ったことをお知らせします。
  2. 内容を確かめ、影響する版と深刻さをお伝えします。
  3. 修正版を用意し、このサイトの更新履歴で、影響する版と修正した版を公開します。
  4. 修正の公開まで、内容を公表しないようお願いします。公表の時期はご相談のうえで決めます。報告者のお名前を載せるかどうかは、ご希望に従います。

対象外

  • 管理者権限を持つ人や、同じユーザーとして動くマルウェアが、端末の中のデータを読めること（OS のログインが破られた状態は、ソフトウェアでは守れません）
  • 短いパスワードや推測しやすいパスワードが、総当たりで破られること

機械で読める形式の連絡先も置いています：/.well-known/security.txt
