let Rust CODING RPG

Rust / Go プログラミングを、RPG形式のバトルや章立て学習、フラッシュカードで学べる教育アプリ。

Google Play で入手

どんなアプリ？

RPG を遊ぶように、Rust と Go のプログラミングを学べる学習アプリです。所有権・借用・ライフタイムといった、つまずきやすい考え方を、武器や敵、スキルになぞらえた世界で、少しずつ身につけられます。

読む・視る・聴く・戦う

  • 読む：全 50 章の本文で、基礎から順に学びます。専門用語は、辞書でその場で確かめられます。
  • 視る：Lab で、所有権の移動や借用がメモリの上でどう動くかを、ステップ実行で見られます。
  • 聴く：章の内容を、音声で振り返るポッドキャストです（対応する章は、順に増やしています）。
  • 戦う：クイズバトルと、章の終わりのコード修復ボス戦。連続で正解するとダメージが上がり、ボスは途中で姿を変えます。

読んだ分、解いた分だけ、キャラクターが育ちます。経験値、ゴールド、称号、デイリーミッションが続ける気持ちを支えます。

Go も、無料で試せます

Go の基礎（Goroutine、チャネル、インターフェースなど全 5 章）を、購入なしで体験できます。

通信しない、買い切りのアプリ

  • 学習のデータはすべてデバイスの中に保存します。広告はありません。
  • 通信するのは、購入の確認のときだけです。
  • 買い切り 980 円で、Rust 本編のすべての章が開きます。追加の課金はありません。

こんな方に

  • プログラミングの経験がなくても、Rust を学んでみたい方
  • 所有権・借用・ライフタイムで、つまずいたことがある方
  • すきま時間に、こつこつ続けたい方
  • ゲーム感覚で、楽しく身につけたい方
