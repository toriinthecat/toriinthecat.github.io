Release notes

Newest first.

0.1.0 November 6, 2026

  • The Android version is now on Google Play.
  • First public release.
  • Create and extract password-protected (AES-256) ZIPs, with every password kept in a ledger.
  • Password-protect PDFs.
  • Identify files by their content, not their extension.
  • A command-line version (vault-zip-cli) for automation.
  • The screens are available in Japanese and English (switch it in the settings).
  • A new icon.
  • The portable version can also run with no passphrase.
  • Password fields have an eye icon to show or hide what you typed.
  • A ZIP that holds a single item is extracted without a folder named after it (you can turn this off in the settings).

Update of November 22, 2026 (build 6)

  • When extraction goes to a fixed folder or a folder you choose each time, an archive holding a single folder no longer ends up as "report eport". Accessory files such as Thumbs.db are not counted.
  • When a folder with the same name already exists, extraction now follows the "When a file with the same name exists" setting (number the new one, rename the old one, or overwrite).
  • The right-click and right-drag menus say where files go: "Extract to "archive name"" and "Extract here". "Compress each" is not shown for a single file, nor "Find out what the file is" for folders only (Windows 11).
  • Android: with "All files access" turned on in the settings, files on the internal storage are extracted and compressed in place and saved next to the original, with no folder to choose each time.
  • Android: Vault-ZIP now appears under "Open with" in file apps. An archive opened this way is not written anywhere until you tap Extract.

Other fixes:

  • An extraction request that arrived just as the app was closing could be dropped without running. Fixed.

Update of November 19, 2026 (build 5)

The screens were reviewed from top to bottom.

  • Compression, extraction and PDF results are shown on cards of the same shape, with the password, notices and details always in the same place.
  • When you create a ZIP, Vault-ZIP asks once whether it should have a password (starting on "no"). You can change the method on the create card and in the settings.
  • Ledger: every row has its own copy button. Selecting a row shows its password, note, files and details beside the list. Sorting is now a choice list.
  • A help page (F1) and a list of keyboard shortcuts (?). Ctrl+1 to 4 switch between the screens.
  • You can choose in the settings how long messages stay on screen.
  • Easier to use with a screen reader and the keyboard (labeled fields, one heading per screen, focus returns where you were). Reduced motion is respected.
  • Android: the back button steps back through screens and windows one at a time.
  • The English screens format dates, numbers and lists the English way.
  • Every component was updated to its latest version (including security updates).

Other fixes:

  • Windows: fixed the right-click menu sometimes staying at the old version after an update. The new menu is used after you sign out and sign back in.
  • Android: "About" now shows the build number.
  • Android: crash reports are easier to trace to their cause (nothing more is sent).

Update of November 8, 2026 (build 4)

  • Settings are now in 11 groups by what you want to do. On phones you pick a group from a list, and you can search the settings. Settings that are rarely changed are under "Advanced".
  • You can choose, item by item, what the right-click and right-drag menus show (Windows, Linux).
  • The right-drag menu has "Compress each here" (Windows).
  • An archive that contains links (symbolic links and the like) is no longer refused: everything else is extracted, the links are not created, and they are listed.
  • Android: fixed the app sometimes not opening from the share menu. PDF encryption now takes files up to 128 MB.
