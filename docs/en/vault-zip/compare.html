The "typical compression tools" column describes what is common among widely used tools; it differs by tool and version, so check your own tool's documentation. "Windows built-in ZIP" is Windows 11 File Explorer; "(not tested)" marks what we have not tried yet.

What Vault-ZIP is not for

  • Creating RAR or 7z files (Vault-ZIP creates ZIP only; it extracts the others).
  • Hiding the file names inside a ZIP (the format does not allow it; see the end of Built with care).
  • Mac and iPhone (Windows only for now; Android is coming).
