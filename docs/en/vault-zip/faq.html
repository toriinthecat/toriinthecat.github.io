FAQ

Is it free?
Free for individuals, including work use (sole traders and side jobs). Schools and other educational institutions use it free without applying. Companies, government offices, incorporated non-profits and other organisations need a licence: 1,000 yen per PC (licence).
Can a ZIP made by Vault-ZIP be opened on a PC without Vault-ZIP?
Yes. Any tool that supports AES-256 encrypted ZIP files (WinZip AES) opens it with the password. We have checked 7-Zip and Windows 11 File Explorer. A ZIP made without a password opens anywhere.
I forgot a password.
For a ZIP made by Vault-ZIP, the password is in the ledger; search it by file name or date. A password that is not in the ledger cannot be found by us either.
What happens to the ledger on a new PC?
The ledger lives on the PC and is encrypted with that PC's key. Before you switch, write a backup from the settings and import it on the new PC. A recovery key is a good idea too.
Are my files or passwords sent over the internet?
No. Vault-ZIP never sends your files, passwords or ledger anywhere without your action, and there is no account and no automatic update check. The background traffic of the window component (Microsoft WebView2) is switched off as well (privacy).
Windows warns me when I download or start it.
Vault-ZIP is not code-signed yet, so Windows may warn. The steps are on the download page. Check that the SHA-256 of the file matches the value listed there before running it.
Which formats can it extract?
ZIP, 7z, RAR, tar, gz, bz2, xz, zst, CAB and MSI, recognised by content rather than extension. Some other formats can be extracted with an external tool you set up (features and specs).
File names from an old ZIP come out garbled.
Vault-ZIP recognises old Japanese ZIP files whose names are in Shift_JIS and extracts them with the right names. It also makes macOS's decomposed names consistent and leaves out the __MACOSX folder and ._ files (this can be changed in the settings).
Some files were extracted under a different name.
Names Windows cannot hold (CON, names with ? or : and so on) and names with invisible characters used to disguise an extension are replaced with usable names. The result of the extraction lists every name that was changed.
On Linux Xfce, "Vault-ZIPで圧縮" does not appear when I right-click the desktop.
The Xfce desktop (the icons over the wallpaper) has no way to add menu items. Right-click files inside a Thunar window instead (see "The right-click menu on Linux" on the download page).
Does it run on Windows 10?
Yes: Windows 10 or later, 64-bit (x64). The new right-click menu is Windows 11 only; on Windows 10 Vault-ZIP appears in the classic menu. Windows on ARM has not been tested.
Can I show a password while sharing my screen?
With "Keep passwords out of screen sharing and captures" turned on in the settings, a window showing a password does not appear in screen sharing, recordings or screenshots (Windows 10 version 2004 or later). It is off by default; an organisation's administrator can turn it on for good.
Can RPA tools use it?
Yes, with the command-line tool vault-zip-cli.exe. It reports results as JSON and success or failure through exit codes. Passwords go through standard input.
I found a bug or have a request.
Please email support@toriinthecat.com with your Windows version, the Vault-ZIP version and the steps. Please do not send passwords or the files themselves.
