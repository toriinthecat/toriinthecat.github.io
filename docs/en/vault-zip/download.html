Install from the command line

You can also install without a browser. The scripts connect to dl.toriinthecat.com only when you run them, and check the signature and SHA-256 before installing.

Windows (PowerShell)

iwr https://dl.toriinthecat.com/install/install.ps1 -OutFile install.ps1
.\install.ps1            # latest version (current user, no administrator)
.\install.ps1 -List      # list versions

Linux (apt: Debian, Ubuntu, Linux Mint)

curl -fsSL https://dl.toriinthecat.com/apt/vault-zip.gpg | sudo tee /usr/share/keyrings/vault-zip.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/vault-zip.gpg] https://dl.toriinthecat.com/apt stable main" | sudo tee /etc/apt/sources.list.d/vault-zip.list
sudo apt update && sudo apt install vault-zip

Linux (script)

curl -fsSLO https://dl.toriinthecat.com/install/install.sh
sh install.sh --user      # no sudo: AppImage and CLI under ~/.local

System requirements

SystemWindows 10 or later (64-bit, x64). Not tested on Windows on ARM. Linux: x64, Debian-family (such as Linux Mint 22).
Also neededMicrosoft Edge WebView2 Runtime. Part of Windows 11 and present on most Windows 10 PCs. Where it is missing, the installer downloads it from Microsoft (the installer connects only in that case).

First start

Vault-ZIP is not code-signed yet, so Windows may warn when you download or start it.

  1. If "Windows protected your PC" appears, click "More info", then "Run anyway".
  2. Check that the file's SHA-256 matches the value above before running it.

On a PC with Windows 11 Smart App Control turned on, unsigned apps may not start.

Uninstalling
