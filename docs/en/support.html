Support

Thank you for using what I make.

Toriinthecat is run by an individual. Vault-ZIP is free for individuals, with no features held back. If you enjoy it, I would be very happy if you supported my work.

Support（coming soon）

What your support goes to

  • Keeping my work going: devices for testing, a code-signing certificate, running this site.
  • Support is entirely optional and changes nothing in what the software can do.
  • Payment happens on an outside payment service's page. We never receive your card details.

Supporting without money

  • Telling others what you like about the software on social media or a blog means a lot.
  • Send bugs and "this is awkward" moments to support@toriinthecat.com.
  • Reading the development journal on note is lovely support too.
