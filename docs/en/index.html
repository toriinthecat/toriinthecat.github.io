About

Toriinthecat is a small software brand run by one person. I design, build and publish everything by hand.

For learning, especially programming, we make game-style educational mobile apps. Keeping up with study is hard, so our apps use RPG-style battles, chaptered stories and flashcards to help learners keep going.

We also make software for Windows for everyday work.
