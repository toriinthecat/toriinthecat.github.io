Toriinthecat について

Toriinthecat は、個人で運営している小さなブランドです。企画から、開発、公開まで、ていねいに取り組んでいます。

今はアプリを作っています。「学ぶことを続けるのはむずかしい」という気持ちに寄りそって、RPG のようなバトルや章立てのストーリー、フラッシュカードで、遊ぶように学べるアプリです。

あわせて、毎日のパソコン仕事で「ちょっと困る」を減らす Windows 用のソフトも作っています。
