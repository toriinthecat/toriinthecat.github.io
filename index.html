Toriinthecat

トリインザキャット ― 学習体験を、遊びのように。

事業内容

Toriinthecat（トリインザキャット）は、プログラミングをはじめとする学習分野を対象に、ゲーム形式の教育モバイルアプリケーションを企画・開発・提供しています。

「学ぶことを続けるのが難しい」という課題に対し、RPG風のバトル・章立てのストーリー・フラッシュカードなど、ゲーム体験を通じて学習の継続を後押しするプロダクトづくりを行っています。

提供中のアプリケーション

  • let Rust CODING RPG
    Rust / Go プログラミングを、RPG形式のバトルや章立て学習、フラッシュカードで学べる教育アプリ。
